Radio networks move messages through the air. KAM helps them stay useful on the ground: it connects a MeshCore KISS radio to a local store, then gives you room to explore, automate, and build.

Meet KAM → Explore the manuals
Current releasev0.5.0 · pre-release The core is implemented, documented, and covered by CI. KAM is still evolving—not a production promise—and its API and configuration may change before 1.0.

A little more than a bridge

Catch it. Keep it. Put it to work.

Built for curious operators who want to understand their network and make something of it—without turning setup into a second hobby.

01 / REMEMBER

Make messages last

Keep decoded radio traffic in local SQLite storage, ready to inspect instead of letting it disappear with the moment.

02 / AUTOMATE

Let small ideas run

Use Starlark scripts to react to group messages, send replies, fetch useful data, and post to rooms.

03 / GATHER

Give the mesh a place

Host MeshCore room servers: shared spaces for people on the network to find, join, and exchange posts.
