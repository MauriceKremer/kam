KAM

KAM (KickAss MeshCore) connects a MeshCore-compatible KISS radio to local storage and automation. It decodes and saves radio traffic in SQLite, runs Starlark scripts, hosts MeshCore room servers, and provides a local REST API.

Status

KAM v0.5.0 is a pre-release build. Its core features are implemented, documented, and covered by CI, but it is not a production promise. The API and configuration may change before version 1.0.
